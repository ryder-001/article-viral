# 爆文规则 - 通用

> 版本: v5 | 更新时间: 2026-06-11 | 来源文章数: 48 | 领域: 通用
> 本次迭代基于 16 篇头条爆款全文分析（微信功能/高考志愿/金价/职场焦虑）

## 标题规则

### 核心公式（按效果排序）
1. **简短悬念式**（本次分析验证最高频） [CONFIRMED]
   - 模板："X + 感叹号/问号"，8-15字极简冲击
   - 示例："微信宣布新功能""金价，一路大跌！""微信又有新功能！"
   - 特点：极短、信息量大、制造好奇心
2. **对比转折 + 数字 + 具体化**（验证爆文：10万+阅读） [CONFIRMED]
   - 模板："真正X的Y，从来不是Z，而是做好这N件小事"
3. **数字列表式**（本次分析：31%文章使用） [CONFIRMED]
   - 模板："一文读懂！N个X问题""N个实用方法Y"
   - 示例："一文读懂！2026高考考生最关心的22个志愿填报问题"
   - 示例："5个实用方法自愈脱困"
4. **痛点共鸣 + 反问** [NEW]
   - 模板："X的根源：你太Y了""找不到X天会塌？"
   - 示例："职场焦虑的根源：你太有责任心了"
   - 示例："找不到工作天会塌？看她如何击碎职场焦虑"
5. **权威背书 + 利益承诺** [CONFIRMED]
   - 模板："权威来源 + 具体数字 + 与你相关的好处"
   - 示例："合力治理高考志愿填报'陷阱'"（人民日报背书）

### 标题参数
- 最佳长度：8-25 字（短标题8-15字适合资讯类，长标题18-25字适合方法类） [NEW: 短标题验证有效]
- 感叹号使用率：44%（本次分析：7/16篇使用，制造紧迫感） [CONFIRMED]
- 问号使用率：19%（制造悬念，引导点击）
- 逗号/冒号分隔率：31%（前半制造悬念，后半给出答案）
- 高频情绪词：新功能、大跌、焦虑、陷阱、一文读懂、如何、实用 [NEW: 新增时事/财经/职场高频词]

### 领域通用模式
- 制造"我之前做错了"的认知冲突 [CONFIRMED]
- 用"普通家庭""普通人"拉近距离 [CONFIRMED]
- 强调"简单可操作"降低行动门槛 [CONFIRMED]
- 痛点焦虑 → 解决方案的情绪转换 [CONFIRMED]
- [NEW] 时事热点类：用最短标题+最快节奏传递信息增量
- [NEW] 职场情感类：用"你是不是这样的人"开头制造代入感

## 结构规则

### 按文章类型区分结构 [NEW]

**资讯快报型**（微信功能、金价等时效性内容）：
- 总字数：300-800字
- 首段直接给结论/新闻事实
- 中间补充细节和背景
- 结尾一句话收束或开放互动
- 示例：文章1/3/9/11（300-700字，信息密度高，无废话）

**深度方法型**（高考志愿、职场自救等知识类内容）：
- 总字数：1200-2500字
- 用编号/小标题分割（H2或数字序号）
- 每个分点内部：观点→案例→行动建议
- 结尾总结+金句
- 示例：文章5/12/13/15（1200-6000字，结构清晰）

**观点评论型**（社会现象分析）：
- 总字数：800-1500字
- 首段抛出现象/数据
- 中间多角度分析原因
- 结尾给出判断或呼吁
- 示例：文章8/15（800-1600字，逻辑层次分明）

### 通用结构规则
- 首段必须在 3 句话内给出核心信息或制造悬念 [CONFIRMED]
- 使用小标题/编号分割段落 [CONFIRMED]
- 采用"总-分-总"结构 [CONFIRMED]
- 关键信息加粗标记重点 [CONFIRMED]
- [NEW] 短段落频繁使用——单独一句话成段是头条爆文常见节奏
- [NEW] "↓↓↓"等引导符号在资讯类文章中高频出现

## 内容规则

### 开篇钩子模式（按效果排序）

1. **直接给结论/新闻** [NEW: 资讯类最有效]
   - 无铺垫，首句即核心信息
   - "10日，'微信派'发文表示：微信朋友圈搜索功能上线"（文章1）
   - "金价在1月29日触及历史高点后，至今已下跌近25%"（文章10）
2. **痛点场景描写** [CONFIRMED: 职场/情感类最有效]
   - 用"你是不是这样"制造瞬间代入
   - "你是不是这样的人：领导随口一句'这个你再想想'，你加班到深夜改了三版"（文章12）
3. **名人金句/事件引入** [NEW]
   - 用一个名人观点作为引子，快速建立话题
   - "2026年6月，作家刘同的一句'人生大事全靠请假完成'，瞬间点燃了全网职场人的共鸣"（文章15）
   - "'找不到工作，天不会塌下来。'这句话出自60岁的退休央视主持人张越之口"（文章16）
4. **反常识/颠覆认知** [CONFIRMED]
   - "你以为X其实Y"
5. **数据震撼式** [CONFIRMED]
   - "全球抑郁症患者已突破3亿人次"（文章14）
   - "45%的职场人'一请假就焦虑'"（文章15）

### 叙事结构模式
- **问题→方案型** [CONFIRMED]：抛出痛点 → 分析原因 → 给出N个解法 → 总结行动
- **故事→感悟型** [CONFIRMED]：人物遇困境 → 转折事件 → 感悟/启示
- **现象→真相型** [CONFIRMED]：列举普遍现象 → 揭示底层原因 → 给出新视角
- **递进式** [CONFIRMED]：浅层观点 → 深一层 → 最深层
- [NEW] **多维分析型**：一个问题从个人/制度/企业/社会多角度拆解（文章15最典型）
- [NEW] **FAQ问答型**：用"问题1""问题2"结构，每问一答，读者自行跳转（文章5/7）

### 节奏与密度规律
- 每 200-300 字插入一个案例、数据或金句 [CONFIRMED]
- 长段落后接短段落制造呼吸感 [CONFIRMED]
- 关键转折处用短句增强冲击力 [CONFIRMED]
- [NEW] 资讯类文章：高密度事实堆叠，每句话都是信息增量，不需要"呼吸感"
- [NEW] 职场/情感类："你"字开头的短段频繁出现，每3-4段回拉读者注意力
- [NEW] 数据引用优先用具体数字而非模糊描述："45%""1270万""3亿"比"很多""大部分"有力

### 情感曲线设计
- **焦虑→安抚→信心型** [CONFIRMED]
- **好奇→满足→行动型** [CONFIRMED]
- [NEW] **共鸣→代价→方法→鼓励型**（职场类标配，文章12最典型）
  - "你是不是这样" → "过度X的三个代价" → "如何改变" → "你值得更好"
- [NEW] **事实→分析→判断型**（资讯评论类）
  - 堆事实 → 给背景 → 下判断

### 口语化与对话感
- "你""我"人称高频使用 [CONFIRMED]
- 口语连接词 [CONFIRMED]
- [NEW] 职场爆文特有话术：
  - "说白了""讲真""你要知道""但你要明白"
  - 短句反问："为什么？因为……""结果呢？"
  - 加粗短句做"金句"效果："**完成比完美重要，交付比纠结重要。**"
- [NEW] 资讯类话术：
  - "具体而言""值得注意的是""此外"（资讯类允许书面语）
  - 用"↓↓↓""来了""划重点"制造信息期待

### 可操作性要求
- 方法类内容必须"可立即执行" [CONFIRMED]
- 每个建议配一个"具体怎么做"的示范 [CONFIRMED]
- [NEW] 职场类用"试着从小事开始"降低行动门槛
  - "试着从小事开始拒绝：'不好意思，我现在手头有点满'"（文章12）
- [NEW] 方法类文章结尾用"这五种方法层层递进"做总结回顾

## 互动规则
- 文末设置开放式问题引导评论 [CONFIRMED]
- [NEW] 资讯类互动模板（验证高频）：
  - "这个新功能你用上了没？觉得怎么样？"（文章3）
  - "你还期待微信更新什么功能？留言区等你"（文章3）
- [NEW] 职场/情感类互动模板：
  - "你有过类似的经历吗？评论区聊聊"
  - 用反问制造站队："你是会拒绝，还是继续忍？"
- 引导转发："转给身边需要的人" [CONFIRMED]

## 平台差异规律 [NEW]

### 头条（今日头条）
- 标题偏短（8-20字），感叹号高频
- 正文信息密度高，废话容忍度低
- 转载自权威媒体的内容传播力强（光明网、人民日报、新华网）
- 图文混排少，纯文字为主
- 结尾常见"来源：XX"标注

### 微信公众号（写作时参考）
- 标题可以更长（18-30字），因为显示空间大
- 正文可以更活泼、更口语化
- 配图、分割线、引用框等排版元素加分
- 结尾互动引导更重要（关乎留言区活跃度）
- 需要制造"转发冲动"（公众号的核心传播方式）

## 爆文验证清单
写完后逐项检查：
- [ ] 标题是否同时包含：情绪触发 + 信息承诺？（短标题可只要信息冲击）
- [ ] 首段是否在 3 句内抓住注意力？
- [ ] 是否有至少 3 个真实/可感知的案例或数据？
- [ ] 读者能否在 3 分钟内读完？（资讯类1分钟，深度类5分钟）
- [ ] 结尾是否设置了明确的互动引导？
- [ ] 是否制造了"我要转给XX看"的冲动？
- [ ] 封面图是否符合规范（见下方封面图规则）？
- [ ] [NEW] 每300字内是否至少有一个具体数字或案例？
- [ ] [NEW] 是否避免了连续3段以上没有"你"字出现？

## 配图与视觉规则

### 配图数量与位置 [NEW]
- **资讯快报型**（300-800字）：0-1张图，放在正文首段后或结尾前
- **深度方法型**（1200-2500字）：2-4张图，每500-800字插入一张
- **观点评论型**（800-1500字）：1-2张图，主图放在首屏
- 配图不宜过密，避免"图片墙"感——每张图之间至少间隔200字正文

### 配图类型选择 [NEW]
| 文章领域 | 推荐配图类型 | 避免 |
|---------|------------|------|
| 科技/产品 | 产品截图、功能示意图、扁平插画 | 纯文字图 |
| 财经/金价 | 数据折线图、K线截图、对比表格图 | 抽象装饰图 |
| 职场/情感 | 场景插画、人物剪影、金句卡片 | 写实人脸照（版权风险） |
| 教育/知识 | 信息图、流程图、步骤卡片 | 堆砌文字的长图 |
| 热点时事 | 新闻现场图、数据可视化 | AI生成的假新闻图 |

### 配图风格要求 [NEW]
- **一致性**：同一篇文章的配图保持统一风格（色调、插画风格、字体）
- **信息增量**：配图应补充文字无法表达的信息（数据可视化、流程图、对比图），而非纯装饰
- **手机友好**：主体元素大，文字清晰可读（手机端图片宽度约375px）
- **安全合规**：不涉及政治、暴力、色情；不使用真人面部照片（除非有授权）

### 配图在文中的标记方式
```markdown
![配图描述](prompt: AI生图提示词)
```
- 描述要明确指出图片应展示什么内容和风格
- 提示词用英文，便于AI生图工具理解

### 首图/封面图与标题的配合 [NEW]
- 封面图的视觉主题应与标题呼应（标题说"大跌"→封面图用下降箭头/红色调）
- 避免封面图和标题信息完全重复（图文互补 > 图文重复）
- 头条位封面（2.35:1）底部20%留白不放内容（公众号会叠加标题文字）

## 封面图规则

### 卡片第一篇（头条位置）
- **比例**：2.35:1 长方形（横向宽图）
- **底部留白**：图片底部 20% 区域**不放任何文字/重要元素**，因为公众号会在此区域叠加文章标题
- **视觉重心**：主要内容集中在图片上半部和中部
- **文字位置**：如需在图片上加文字，放在图片上部 1/3 区域

### 卡片非头条位置（第2-8篇）
- **比例**：1:1 正方形
- **文字可居中**：标题区域在左侧，图片右侧展示，无遮挡问题

### 通用要求
- 风格醒目、色彩对比强，适合手机端小图浏览
- 避免过多细节，主体元素要大
- 符合文章调性（商业→professional，情感→warm，时事→bold）
