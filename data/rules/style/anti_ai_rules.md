# 去 AI 味写作规则

> 版本 1.0 | 目标：让生成文章通过 AI 检测，读起来像真人写的

## 一、禁用词清单（AI 高频连接词）

以下词汇在正文中**严禁使用**，出现即扣分：

```
此外、另外、然而、总之、综上所述、值得注意的是、
需要指出的是、不可否认、毋庸置疑、总而言之、由此可见、
换言之、具体而言、简而言之、从某种程度上说、与此同时、
更重要的是、显而易见、不言而喻、归根结底、
在这个过程中、从本质上讲、客观来说、总的来说
```

**替代方案**：
- 不用连接词，直接换行分段
- 用口语过渡："说到这个""对了""话说回来"
- 用短句断开："但是。""不对。""等等。"

## 二、句长随机化

| 要求 | 说明 |
|------|------|
| 短句占比 ≥ 25% | 15字以内的句子至少占1/4 |
| 长句占比 ≥ 15% | 40字以上的句子要有一些 |
| 禁止连续3句等长 | 相邻句子长度差异要明显 |
| 偶尔用不完整句 | "就很离谱。""真的。""懂的都懂。" |

## 三、口语化强制标记

每3段**至少包含1个**以下元素：

- 语气词："啊、呢、吧、嘛、哎、哈"
- 主观表达："我觉得""讲真""说实话""不瞒你说"
- 反问/设问："你说是不是？""这谁顶得住？"
- 不完整句："就…很无语。""真的会谢。"
- 感叹/夸张："绝了！""太离谱了""笑死我了"

## 四、段首词不重复约束

- 相邻段落**禁止**用相同词语/句式开头
- 段落开头优先用：对话、数字、场景、动作
- 好的段首示例：
  - "4:30，闹钟响了。"
  - "朋友问我……"
  - "说个真事儿。"
  - "翻了一下数据，"
  - "结果你猜怎么着？"

## 五、具体化要求

| 禁止（抽象） | 替换为（具体） |
|-------------|--------------|
| 很早起床 | 4:30起床 |
| 一段时间后 | 3周后 |
| 取得了很好的成绩 | 涨粉2.3万 |
| 经过深入研究 | 翻了87篇论文 |
| 很多人都说 | 评论区327条都在问 |

## 六、节奏感（呼吸感）

模拟真人写作的节奏变化：

```
短短短。长~~~~~长~~~~~长。短。
中中中中。短。长~~~~~长~~~~~。短短。
```

具体做法：
- 每写3-4个正常句，插入1个超短句（<8字）
- 关键观点前，用短句做铺垫
- 段尾偶尔用不完整句收尾，留白

## 七、自检清单

生成文章后对照检查：

- [ ] 全文无禁用连接词
- [ ] 短句（<15字）占比 ≥ 25%
- [ ] 每3段至少1个口语化标记
- [ ] 相邻段落开头不重复
- [ ] 至少3处具体数字/细节
- [ ] 至少2处主观表达（我觉得/讲真/说实话）
- [ ] 有至少1个不完整句或省略句
- [ ] 读出来像"说话"而非"写文章"
