# 微信公众号平台规则

> 版本: v1 | 更新时间: 2026-06-12 | 来源: 实战验证

## 流量分配机制

微信公众号和头条不同，**不是纯算法推荐**，而是社交推荐+官方推荐混合。官方推荐有明确的内容调性偏好。

## 限流/不推荐的内容类型

| 类型 | 特征 | 为什么限流 |
|------|------|-----------|
| **贩卖焦虑** | 35岁危机、职场被裁、中年失业、阶层固化 | 平台不鼓励制造社会焦虑 |
| **负面情绪** | 标题含"太难了""崩溃""绝望"等强负面词 | 影响用户体验 |
| **对立煽动** | 挑起群体对立、制造愤怒 | 违反社区规范 |
| **标题党** | 过度夸张、与内容不符 | 被举报后降权 |

## 推荐/有流量的内容类型

| 类型 | 特征 | 为什么有流量 |
|------|------|------------|
| **正向解决方案** | "省钱妙招""生活变好""轻松搞定" | 实用+正能量 |
| **实用工具/教程** | "功能教程""避坑指南""一文读懂" | 收藏价值高 |
| **生活美学** | "小空间改造""断舍离后的生活" | 正向生活态度 |
| **知识科普** | 健康常识、理财入门、育儿知识 | 转发到家族群 |
| **暖心故事** | 正能量人物、温暖瞬间 | 情绪正向 |

## 选题避坑清单

写文章前必须过这个 checklist：

- [ ] 标题是否传递焦虑感？（如果是 → 换个正向角度重写）
- [ ] 核心情绪是向上的还是向下的？（向下 → 调整为"问题→解法→希望"）
- [ ] 读完后读者感受是"我完了"还是"我可以"？（必须是后者）
- [ ] 是否可能被举报为"贩卖焦虑"？

## 焦虑话题的正向改写策略

同一个话题可以换角度写，避开限流：

| 焦虑型（限流） | 正向型（有流量） |
|---------------|-----------------|
| "35岁被裁后的绝望" | "35岁转行成功的3个真实故事" |
| "职场PUA太难了" | "识别PUA后，我用3招扭转了局面" |
| "房贷压力大到崩溃" | "从月光到月存5千，我只改了3个习惯" |
| "中年失业怎么办" | "40岁裸辞后，我找到了比上班更好的活法" |
| "内卷到底有多严重" | "退出内卷后，我反而升职了" |

**核心原则：同一个痛点，不贩卖痛苦，而是给出路。标题传递的是"解法"和"希望"，而不是"问题"和"绝望"。**

## 与头条的对比

| 维度 | 微信公众号 | 今日头条 |
|------|-----------|---------|
| 焦虑内容 | 限流 | 可推荐（高点击率） |
| 标题风格 | 正向、实用、好奇 | 冲击、争议、焦虑也行 |
| 内容调性 | 偏正能量 | 中性，看数据表现 |
| 传播方式 | 社交转发+官方推荐 | 纯算法推荐 |
| 长度偏好 | 800-1500字 | 300-2000字都行 |
