# 配图与视觉规则

> 版本: v1 | 更新时间: 2026-06-06 | 来源: guizang-social-card-skill 设计体系分析

## 核心原则

**做杂志，不做网页。** 公众号图文在信息流中被滑过，本质和印刷海报一样——用一张静态图在1秒内说服读者停下来。网页设计语言（Tailwind大色块+emoji堆砌）搬到静态图上会显得用力过猛、信息平淡。

## 一、配图来源优先级

按效果和安全性排序，优先用真实图，AI生图是最后手段：

1. **真实摄影图**（Pexels/Unsplash）— 质感最强，不会被平台标注AI
2. **截图美化**（产品界面/聊天记录/数据截图加设备框）— 信息量大，有说服力
3. **素材二创**（原图+AI改构图/改背景/改主体）— 保留爆款元素又规避重复
4. **AI生图**（仅当前三项都无法满足时）— 必须加风格约束词，避免"一眼AI"

### AI生图注意事项
- 强制带风格约束词（胶片/杂志/纪实），避免默认插画风
- 不追求完美，有瑕疵有时比完美流量更高
- 人物类：放远/用背影，不做正脸（太容易被识别为AI）
- 平台会标注AI图片水印 → 被标注容易限流

## 二、品类视觉适配

不同内容类型需要不同的视觉语言，一套模板套所有内容是最大的错误：

| 内容品类 | 推荐视觉风格 | 图片倾向 |
|---------|------------|---------|
| 育儿/教育 | 暖色杂志风，留白多，衬线标题 | 亲子场景摄影、手绘插图 |
| 职场/干货 | 网格风，深色背景，数据大字报 | 截图美化、信息图表 |
| 情感/故事 | 杂志风，电影海报式，人物特写 | 生活场景、背影、侧影 |
| 美食/探店 | 高饱和杂志风，文字向四角让位 | 俯拍食物、环境氛围 |
| 怀旧/回忆 | 胶片/复古色调，颗粒感 | 老照片、旧物件、年代场景 |
| 对比/反差 | 左右分割/上下对比，强对比色 | 前后对比图、VS拼图 |

## 三、文字压图规则

文字压图是配图最容易翻车的环节，遵循三步法：

1. **识别主体避让**：人脸、产品中心、文字密集区不放文字
2. **色值适配**：算落点区域明度 → 浅底用深字/深底用亮字 → 必要时加半透明蒙版
3. **字号断行自适应**：根据可用区域动态调字号和换行，不写死尺寸

### 常见翻车场景（必须避免）
- 文字盖在人脸或产品核心位置
- 白字压浅色背景看不清
- 文字横跨整张图破坏构图

## 四、截图美化四件套

产品截图、聊天记录、数据截图的美化流程：
1. **设备外框**：加 macOS/iOS 风格边框（浏览器窗口或手机壳）
2. **背景材质**：格纸、点阵、暖白或深色纯色，不让截图白底飘在白底上
3. **阴影层次**：根据整体风格匹配阴影深度和圆角
4. **尺寸裁切**：突出关键信息区域，裁掉无关部分

## 五、版式骨架（约束出品质）

核心理念：**AI做"填充"，不做"设计"**。给AI一个被验证过的骨架，成品稳定性远高于让它自由发挥。

### 公众号文章配图参数
- 宽度：900px（公众号标准宽度）
- 封面图比例：2.35:1（横版）
- 文中配图比例：16:9 或 4:3
- 图文间距：上下各留 20px 呼吸空间

### 设计约束（限制=底线）
- 单篇文章配色不超过 3 个主色
- 字体层级最多 3 级（标题/正文/注释）
- 每张图一个视觉重心，不堆砌信息
- 用色克制：信息流里克制的色板比饱和度高的更抢眼
